# Admin Bilik Farm — Hors périmètre MVP

## Statut

Cette interface n'est pas connectée à un backend validé et ne doit pas être considérée comme fonctionnelle.

## Interdictions

- ne pas déployer;
- ne pas exposer publiquement;
- ne pas créer de comptes;
- ne pas présenter les données de démonstration comme réelles;
- ne pas utiliser comme CMS de production.

## État connu

- authentification non validée;
- autorisations non validées;
- API absente;
- données statiques ou de démonstration;
- tests absents;
- sécurité non auditée.

## Condition de réouverture

Une phase dédiée devra définir les rôles, permissions, API, sécurité, tests et stratégie de déploiement.
