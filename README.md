# bilik-farm

Bilik Farm est un projet de site web et CRM pour une ferme intégrée combinant agriculture et élevage. Le site public présente la ferme, ses activités, ses produits, sa vision et ses services. Le CRM interne permet de gérer les opérations agricoles, les ventes, les clients, les stocks et le suivi administratif.

Le projet vise à soutenir la croissance d’une ferme moderne, structurée et orientée production. Il peut servir à suivre les cultures, les animaux, les récoltes, les ventes, les dépenses, les clients et les partenaires.

Bilik Farm est pensé comme une base numérique pour professionnaliser la gestion d’une ferme intégrée et préparer son développement commercial.

Fonctionnalités principales :

* Site vitrine de la ferme
* Présentation des produits agricoles
* Présentation des activités d’élevage
* Gestion des clients
* Gestion des ventes
* Gestion des stocks
* Suivi des cultures
* Suivi des animaux
* Tableau de bord CRM
* Rapports internes
