# Backend Bilik Farm — Hors périmètre MVP

## Statut

Ce backend n'est pas exécutable ni approuvé pour le MVP actuel.

## Interdictions

- ne pas installer les dépendances;
- ne pas lancer le serveur;
- ne pas exécuter Prisma;
- ne pas exécuter le seed;
- ne pas utiliser en production;
- ne pas restaurer de données fictives;
- ne pas créer de compte admin codé en dur.

## État connu

- manifeste de dépendances incomplet;
- migrations non validées;
- sécurité non validée;
- authentification non validée;
- tests absents;
- déploiement non défini.

## Condition de réouverture

Une directive PM dédiée doit approuver :

- l'architecture;
- les dépendances;
- les migrations;
- la gestion des secrets;
- l'authentification;
- les tests;
- le déploiement.
